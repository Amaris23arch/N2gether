# N2gether 🌸

Dark-mode JLPT N2 study companion.

Includes:
- N2 Journey dashboard
- N2 vocabulary and kanji libraries using OpenJLPT data
- 100 curated important N2 grammar patterns
- Original Chōkai practice using browser speech synthesis
- Mini mock test
- Browser-based XP/mastery

Data note: JLPT does not publish a fixed official post-2010 word/kanji list. OpenJLPT documents community-standard N2 coverage and licenses its dataset CC BY-SA 4.0.
Source: https://github.com/evanclan/OpenJLPT
